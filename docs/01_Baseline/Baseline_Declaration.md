# VIT SMART — Baseline Declaration

## 1. Project Starting Point

VIT SMART is a continuing student venture developed from the previous academic year.

The project was originally designed as a smart exercise feedback system focused on EMG-based muscle fatigue monitoring. The previous concept combined EMG sensing, signal processing, pose input and simplified real-time feedback to help exercise users make clearer training decisions.

The team has already developed a preliminary system architecture, explored a three-state feedback model, and conducted initial user testing.

---

## 2. Previous Outputs

The previous development cycle produced the following outputs:

- VIT SMART Demo Day presentation
- Preliminary EMG signal-acquisition and processing concept
- Real-time EMG waveform visualisation
- Three-state feedback model: Normal / High Load / Fatigue Risk
- Preliminary pose-analysis architecture
- Initial user-testing activities
- Identification of EMG signal-stability limitations during movement

Previous artefacts that can still be located are being retained in the Evidence Hub.

---

## 3. What Has Changed

After reviewing the previous prototype, the team identified a major limitation in the EMG-based fatigue-monitoring approach.

The previous fatigue-classification thresholds were not supported by sufficient physiological validation, and EMG signal stability can be affected by factors such as sensor placement, body movement and exercise type.

Some original raw evidence from the previous project cycle may also no longer be available.

As a result, the team is not treating the previous EMG fatigue-classification approach as fully validated.

The team is now reconsidering whether EMG should remain the core of the system or whether posture / movement-quality feedback should become the primary direction.

---

## 4. What Will Be Re-Validated This Semester

The team will collect fresh evidence to re-validate the following:

- Whether the current problem remains significant for target users
- Who the primary target user should be
- Whether users value fatigue feedback, posture feedback, or a hybrid form of exercise guidance
- Whether EMG signals can provide sufficiently reliable and defensible exercise feedback
- Whether pose-based movement analysis provides a more practical and actionable solution
- Current competitors and substitutes
- Market size and demand assumptions
- The value proposition and future business model

The final direction of VIT SMART will be selected using fresh user, technical and market evidence rather than relying only on the previous prototype.

---

## 5. Current Baseline Position

VIT SMART has progressed beyond the idea stage and has prior technical development and preliminary user-feedback evidence.

However, the project still contains important technical and evidence gaps that must be addressed during the current ENT303TC development cycle.

The immediate priority is therefore to re-validate the core problem and compare the EMG-based, pose-based and hybrid directions before committing to the next prototype.
